# 🔥 #7 複合リスク分析

**ここが作品の核心。**

単純に脆弱性を並べるだけではなく、

```text
A：管理画面が公開
+
B：認証設定に問題
+
C：権限設定に問題
```

のように、**複数のFindingの組み合わせによるリスク**を分析する。

* [ ] リスクルール設計
* [ ] Finding間の関連付け
* [ ] 複合条件判定
* [ ] リスク増幅ロジック
* [ ] 複合リスクの説明生成

**成果物：**

> 「単体では中程度の問題ですが、複数の問題が組み合わさることで重大なリスクにつながる可能性があります」

と説明できる。

## 🎯 優先順位

特に重要なのはここ。

**#2〜#6**
→ 「動く診断システム」

**#7〜#9**
→ **「RiskTrace独自の価値」**

**#10〜#12**
→ 「企業が使える形」

**#13〜#15**
→ 「作品としての完成度」

だから、まずGitHubには**#2からIssueを1個ずつ作っていけばOK**。

そして開発中に「これ無理やん」ってなったら、機能を削るのは全然アリ。
逆に#7の**複合リスク分析**だけは、今回の作品の看板としてなるべく残したい。
