適用方法
1. 念のため、現在の上記2ファイルをバックアップします。
2. ZIPを C:\Users\cre\RiskTrace に展開し、同じパスのファイルを上書きします。
3. PowerShellで次を実行します。

   python -m py_compile scanner/port_check.py
   python -m unittest discover -s tests -v

M5の変更内容
- 実際のTCP接続から得られたpeer IPを使って、ループバック／プライベート／リンクローカル／グローバル／特殊用途／不明に分類します。
- ループバック限定で検出した要確認ポートはINFOとし、外部公開の証拠ではないことを記載します。
- 接続先が内部／グローバルのケースでも、接続成功だけでインターネット全体からの到達性を証明しないと説明します。
- TCP接続のみ、HTTP応答確認、TLSハンドシェイク確認をEvidenceに明示し、ポート番号だけでサービスを断定しません。
- Serverヘッダーは偽装可能な未検証バナーとして記録します。
- TLS証明書の検証失敗Findingにもネットワーク範囲の文脈を加え、ループバックだけの場合はINFOにします。
- 4つのM5自動テストを追加しました。

注意
- TCP接続で確認できるのは、検査を実行した端末からその宛先ポートに接続できたことです。別の端末やインターネットからの到達性は証明しません。
